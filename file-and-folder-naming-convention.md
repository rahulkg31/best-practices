## Folder Naming

### Best Practice

- use lowercase
- use hyphens
- avoid spaces
- keep names short

### Standard

```
project-name
```

or when dates are useful:

```
yyyy-mm-dd-project-name
```

### Examples

```
website-redesign
2026-05-13-product-launch
```

------

## File Naming

### Standard

Simple:

```
name-description.ext
```

With dates and versions when needed:

```
YYYY-MM-DD_name-description_v01.ext
```

### Best Practice

- use lowercase
- use hyphens
- avoid spaces
- use ISO dates when needed
- use version numbers (`v01`, `v02`) for revisions

### Examples

```
file-and-folder-naming-convention.md
2026-05-13_marketing-quarterly-performance-report_v02.xlsx
```
